# MyWorth Web Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent manual dark mode toggle.

**Architecture:** App owns the theme mode state, persists it to local storage, passes it to Settings, and applies a `data-theme` attribute plus Ant Design theme algorithm. CSS uses variables for non-Ant Design surfaces.

**Tech Stack:** React, TypeScript, Ant Design, CSS variables.

## Global Constraints

- Keep bottom navigation at five tabs.
- Keep blue gradient cards.
- Default to light mode.
